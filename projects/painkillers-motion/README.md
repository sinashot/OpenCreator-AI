# موشن گرافیک «مسکن‌ها چطور کار می‌کنن؟»

ریلِ اینستاگرامی ۹:۱۶ (۱۰۸۰×۱۹۲۰، ۳۰ فریم) که کاملاً با کد ساخته شده (Remotion). صدای ویدیوی اصلی استفاده نشده؛ گویندگی، موسیقی و افکت‌ها همه تازه ساخته شده‌اند.

- **گویندگی:** TTS فارسیِ آفلاین (Piper، صدای `fa_IR-ganji-medium`) با کنترلِ مستقیمِ واج‌ها. تلفظِ کلماتی مثل «مُسَکِّن»، اسمِ داروها و حالتِ محاوره‌ای («می‌شه»، «یه»، «که») در فرهنگِ تلفظِ `audio/lex.tsv` تنظیم شده.
- **موسیقی:** قطعه‌ای اورجینال با ۱۰۰ BPM در لا مینور که در `audio/compose_music.py` با کد نوشته شده. شروعِ هر بخش روی بیت می‌افتد و در همان لحظه دوربین با «ویپ‌پن» حرکت می‌کند.
- **تصویر:** همه‌ی صحنه‌ها روی یک نوارِ افقی چیده شده‌اند و یک دوربین از راست به چپ بین‌شان حرکت می‌کند. صحنه‌ها با فید به هم وصل نمی‌شوند. هر دسته‌ی دارو رنگِ مخصوصِ خودش را دارد.

## ساختن دوباره

```bash
npm install
# ۱. گویندگی (نیاز به مدل‌های Piper و espeakng-loader، onnxruntime)
#    خطوط در audio/lines.tsv، تلفظ‌ها در audio/lex.tsv
# ۲. تایم‌لاین و موسیقی
python3 audio/build_timeline.py VO_DIR audio/lines.tsv
python3 audio/compose_music.py src/timeline.json public/audio
# ۳. رندر
npx remotion render src/index.ts Painkillers out/painkillers.mp4
```

برای عوض کردنِ متنِ روی صفحه به `src/scenes/` سر بزنید. اسمِ پیج را هم می‌توانید در `src/scenes/Outro.tsx` اضافه کنید.
