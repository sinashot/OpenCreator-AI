# ریلز واکسن تب برفکی — ویرا واکسن شایا

موشن‌گرافیک عمودی (۹:۱۶، ۱۰۸۰×۱۹۲۰، ۳۰ فریم، ۸۲ ثانیه) برای ریلز اینستاگرام؛ خلاصه‌ی ویدیوی «راهنمای واکسن‌های تب برفکی».

Output: `out/fmd-vaccine-reel.mp4`

## Structure (120 BPM, 1 bar = 2 s, every section change is a whip pan on a downbeat)

| Time | Section |
|---|---|
| 0–8 s | Hook: FMD capsid, then antibodies bind it — «چه چیزی یک واکسن را واقعاً مؤثر می‌کند؟» |
| 8–16 s | The six criteria |
| 16–24 s | ۱ متوقف کردن شیوع (transmission chain broken by a shield) |
| 24–32 s | ۲ تطابق با سویه‌ها (antibodies matching serotypes O, A, Asia1) |
| 32–40 s | ۳ توان ایمنی‌زایی (antibody titre vs. protection threshold) |
| 40–48 s | ۴ عاری بودن از NSP (vaccinated vs. infected, DIVA test) |
| 48–56 s | ۵ سرم‌ها و ایمنی زیستی (checklist) |
| 56–64 s | ۶ کیفیت در برابر هزینه (balance scale) |
| 64–72 s | Verdict / closing question |
| 72–82 s | «تهیه‌شده توسط شرکت ویرا واکسن شایا» (final hit at 78 s) |

## Render

```bash
npm install
npx remotion render src/index.ts Reel out/fmd-vaccine-reel.mp4
```

`remotion.config.ts` points at the pre-installed headless Chromium in this cloud container; remove the `setBrowserExecutable` line on a normal machine.

Music: original Shur-mode track (`public/music/shur-pulse.mp3`) and whooshes generated by the persian-motion-director skill's `compose_shur_pulse.py`. Font: Vazirmatn (OFL).
