# اوردوز همیشه به خاطر مصرف زیاد نیست — موشن گرافیک

ویدیوی عمودی ۷۵ ثانیه‌ای (۱۰۸۰×۱۹۲۰، ۳۰ فریم بر ثانیه) با صدای راوی خود ویدیوی مرجع.

- ایده‌ی اصلی: یک مانیتور تنفس که از ثانیه‌ی اول روی صفحه است و در طول ویدیو آرام‌آرام می‌میرد (۱۶ تنفس در دقیقه ← ۰)، با صدای نفس‌کشیدن و ضربان قلبی که کند می‌شود.
- ترکیب سبک‌ها: شروع وحشت با متن گلیچ، تایپوگرافی جنبشی فارسی، دیاگرام پزشکی خطی با نئون و لرزش دست‌کشیده، اینفوگرافیک منحنی تصاعدی، کات‌های فلش روی ضرب، و خاموش شدن تلویزیون قدیمی (CRT) در پایان.
- پایان‌بندی: پیام پیشگیری («هیچ‌وقت مسکن رو با الکل مصرف نکن»)، دعوت به ارسال برای عزیزان، و یادداشت آموزشی.
- `src/` — کد انیمیشن، زمان‌بندی کلمات، رندر و طراحی صدا
