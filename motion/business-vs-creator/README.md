# بیزینس یا کریتور؟ — موشن گرافیک

ویدیوی عمودی ۳۰ ثانیه‌ای (۱۰۸۰×۱۹۲۰، ۳۰ فریم بر ثانیه) بر اساس دیالوگ ویدیوی مرجع. هیچ تصویری از ویدیوی مرجع استفاده نشده و صدای گوینده هم کاملاً عوض شده است.

- `business-vs-creator.mp4` — خروجی نهایی (صدای جدید + موسیقی اورجینال + افکت، ‎-14 LUFS)
- `src/index.html` — انیمیشن کانواس (تابع خالص زمان)، فونت وزیرمتن
- `src/render.js` — رندر فریم‌به‌فریم با Playwright و ffmpeg
- `src/music.py` — موسیقی ۱۲۰ BPM در دستگاه شور و افکت‌های صوتی، ساخته‌شده با کد

صدای گوینده: ElevenLabs (eleven_v3، صدای «Setareh»).
