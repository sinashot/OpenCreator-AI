# موشن‌گرافیک «مریم» — ذهنی که شب‌ها بیدار می‌ماند

یک موشن‌گرافیک برنامه‌نویسی‌شده با [Remotion](https://www.remotion.dev) (React + SVG)، عمودی برای اینستاگرام، سینک‌شده با نریشن ویدیوی اصلی.

| مشخصه | مقدار |
|---|---|
| ابعاد | ۱۰۸۰ × ۱۹۲۰ (۹:۱۶) |
| نرخ فریم | ۶۰ فریم بر ثانیه |
| مدت | ۶۳٫۱۳ ثانیه (۳۷۸۸ فریم) |
| صدا | نریشن جداشده از ویدیوی منبع، بدون بازکدگذاری (`public/audio/narration.m4a`) |
| فونت | Vazirmatn (وزن ۸۰۰)، داخل پروژه، مجوز OFL |
| تصویر خارجی | هیچ؛ همه‌ی گرافیک‌ها SVG و کد هستند |

## اجرا

```bash
npm install
npm run preview   # پیش‌نمایش با کنترلر پخش: http://localhost:5173
npm run studio    # Remotion Studio
npm run render    # رندر نهایی → out/maryam-motion.mp4
```

در محیطی که Chrome Headless Shell خود Remotion دانلود نمی‌شود، مسیر یک Chromium محلی را بدهید:
`npm run render -- --browser-executable=/path/to/chrome`.

### کنترلر پیش‌نمایش (`preview/`)
- پخش/توقف (دکمه یا Space)، نوار زمان راست‌به‌چپ، پرش ±۱ ثانیه با کلیدهای جهت.
- نوار رنگی زیر تایم‌لاین: ۱۸ بخش، رنگ هر صحنه؛ کلیک روی هر بخش به شروع آن می‌پرد.
- «فایل نریشن»: یک فایل صوتی/ویدیویی دیگر را جایگزین نریشن می‌کند و همان تایم‌لاین را با آن پخش می‌کند.
- کنترلر بیرون از کامپوزیشن است، پس در رندر نهایی وجود ندارد. با `?clean` در آدرس برای ضبط صفحه هم پنهان می‌شود.

## سینک با صدا

زمان شروع هر ۲۱۱ کلمه از زیرنویس کلمه‌به‌کلمه‌ی ویدیوی منبع اندازه‌گیری شده (`tools/word_onsets.py`) و با سکوت‌های فایل صوتی چک شده است. `tools/build_timeline.py` متن ۱۸ بخش (`tools/segments.json`) را کلمه‌به‌کلمه با نریشن تطبیق می‌دهد و `src/data/timeline.json` را می‌سازد:

```json
{
  "id": "4a",
  "sceneId": 4,
  "startTime": 26.2,
  "endTime": 30.5,
  "fullText": "مریم هر شب، بدون اینکه بدونه، داشت به مغزش پیام «بیدار بمون» می‌داد.",
  "highlightedPhrase": "بدونه، داشت به مغزش",
  "words": [{"text": "مریم", "start": 26.2}, "..."]
}
```

هر بخش با اولین کلمه‌ی گفته‌شده‌اش شروع می‌شود، پس مرزها به‌جای ثانیه‌های گرد، دقیقاً روی صدا هستند (مثلاً ۵-ب در ۴۲٫۱۷ به‌جای ۴۱).
رویدادهای تصویری هم به کلمه‌ها گره خورده‌اند؛ مثلاً `W('5a', 4)` یعنی لحظه‌ی گفتن «تغییرهای»، وقتی گوشی برمی‌گردد.

## موتور تایپوگرافی (`src/components/KineticText.tsx`)
- `highlightedPhrase` را خودش داخل `fullText` پیدا می‌کند (بی‌توجه به علائم نگارشی و نیم‌فاصله)، در خط دوم و با رنگ ‎#9EFF00‎ و Scale-in نرم نشان می‌دهد.
- هر کلمه روی زمان گفته‌شدنش ظاهر می‌شود (Pop & Fade)؛ جای همه‌ی کلمه‌ها از اول رزرو است، پس خط جابه‌جا نمی‌شود.
- اندازه‌ی هوشمند: هر خط اندازه‌ی خودش را برای پهنای ستون می‌گیرد و اگر خیلی ریز شود، دو خط می‌شود.
- قواعد فارسی: انیمیشن روی کل کلمه (نه حرف)، `dir="rtl"` روی هر خط، بدون letter-spacing.

## ساختار

```
src/
  data/timeline.json      تایم‌لاین ۱۸ بخش + زمان هر کلمه
  components/             تایپوگرافی، پس‌زمینه (داستان رنگ)، نویز و vignette
  art/                    کاراکتر قابل‌ژست‌گیری (مورفینگ بین ژست‌ها)، مغز، ساعت، چرخ‌دنده، آیکون‌ها
  scenes/
    BedTop.tsx            ۱-الف تا ۲-الف: خیره به سقف، ذهنِ دونده، حلقه‌ی ∞ و باتری
    Desk.tsx              ۲-ب، ۲-ج: تایم‌لپس ماه‌ها، شیرجه به قفسه‌ی سینه و کلاف لرزان
    Mind.tsx              ۳-الف تا ۴-الف: حباب‌های فکر، ذره‌بین، کلید ON، شبکه‌ی عصبی و تابلو نئون
    Room.tsx              ۴-ب تا ۶-الف: نور گوشی، کالبد نورانی، تغییرهای کوچک، موج‌های تنفس، نور صبح
    Calm.tsx              ۶-ب تا ۶-د: مغز آرام، هاله، علامت سؤال
  MaryamFilm.tsx          کامپوزیشن اصلی
preview/                  اپ پیش‌نمایش با کنترلر
tools/                    استخراج زمان کلمه‌ها و ساخت تایم‌لاین
```
